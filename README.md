# Giovanni “Gio” Fiore

Solutions engineer building local developer tools for PostgreSQL, code review,
and AI agent workflows. I work across the CLI, backend, and interface in
TypeScript and Python.

**Start with [SQLSage](https://github.com/Figo5/sqlsage):** explain a PostgreSQL
query and investigate correctness risks before tuning its performance.
Try a bundled example with Node.js 22.18+; no database or account needed:

```sh
npx sqlsage demo
```
